Exclusão de Conta

Última atualização: março de 2026

O aplicativo Looro permite que os usuários façam login utilizando uma conta do Google.

Caso você deseje excluir sua conta do Looro e os dados associados, siga as instruções abaixo.

Como solicitar a exclusão da conta

  1. Envie um e-mail para contato@looro.app
  2. Use o assunto: "Solicitação de exclusão de conta"
  3. Informe o e-mail utilizado para fazer login no aplicativo

Dados que serão excluídos

  • Informações da conta do usuário (e-mail do Google e ID do usuário)
  • Progresso de aprendizado
  • Preferências do usuário

Dados que podem ser mantidos

Dados de análise anônimos que não identificam o usuário podem ser mantidos para fins estatísticos e de melhoria do serviço.

Prazo para exclusão

As solicitações de exclusão de conta são processadas em até 7 dias.

Contato
